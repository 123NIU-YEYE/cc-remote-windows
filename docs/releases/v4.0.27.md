# cc-remote v4.0.27

## 中文

本版修复 Hugging Face 等网站的图片预览，并改善 GitHub 等单色图标在深色及自定义主题下的辨识度。
通信协议保持 **v78**，与 v4.0.26 相同；Claude Agent SDK 保持 **0.2.157**。

### 链接预览与图标

- 将源图片下载上限与最终缩略图大小分开：源图片最多 1 MiB，源图标最多 256 KiB，兼容较大的社交封面及多尺寸 ICO。
- 图片解码后最多进行四次有界缩放编码，输出仍为不含元数据的静态 PNG，图片最多 256 KiB、图标最多 64 KiB。
- GitHub 等透明中性单色图标使用主题文字色，在消息链接及预览卡片标题中保持可见。
- 彩色、不透明及具有内部明暗细节的图标保留原貌；分类失败时回退至原图。
- 保留公网地址校验、像素预算、解码并发限制和无图片时的文字预览，不改动会话、模型调用或通信协议。

### 升级与附件

按[部署流程](https://github.com/muggle-stack/cc-remote/blob/v4.0.27/deploy/README.md)更新已安装服务并重新加载 Web 客户端。本版没有跨协议升级；普通 Wrapper 更新仍保留独立 Claude 服务。

- 六个 Relay/Wrapper 平台包、`install.sh`、`SHA256SUMS` 由 GitHub Actions 构建并提供 attestation。
- `cc-remote-android-v4.0.27.apk`：已签名，沿用原签名身份；原生版本保持 `0.1.0-preview.2`（versionCode 2）。
- `cc-remote-harmony-v4.0.27-unsigned.hap`：原生版本保持 `0.1.0-preview.5`（versionCode 5）；**未签名，需使用自己的开发者及设备 Profile 签名，不能直接安装。**
- `MOBILE_BUILD_INFO.json`、`MOBILE_SHA256SUMS` 记录移动端源码提交和校验值；移动端附件从本 tag 的受跟踪源码本地构建，不属于 GitHub Actions attestation 覆盖范围，也不包含私人签名材料或推送服务密钥。

Android preview.2 与鸿蒙 preview.5 用户无需为本次更新重装原生应用，重新加载已更新服务的页面即可。本次不提供 iOS 或 Desktop 安装包；DSH 分支的 Desktop 外部浏览器跳转修复不在本次主分支发布范围内。发布本身不会更新线上服务或已安装应用。

### 验证范围

- 完整本地检查：6,224 项 Python 测试通过、5 项预期跳过；Node 24 Web 构建、可靠性检查、Lint、Ruff、Bash 语法及 ShellCheck 通过。
- 26 项 Chromium／WebKit 浏览器检查通过，覆盖链接预览、图标主题适配及既有预览交互。
- Android 单元测试、Lint、构建、签名与对齐检查，以及鸿蒙 Release 编译和包内容检查通过。

浏览器检查不替代所有原生 WebView 真机验收。本次没有重新验证完整 Android／鸿蒙设备流程，也未发送模型测试消息。

## English

This release restores image previews for sites such as Hugging Face and keeps
monochrome icons such as GitHub's readable in dark and custom themes. Wire
protocol remains **v78**, the same as v4.0.26; Claude Agent SDK remains **0.2.157**.

### Changes

- Separate source download budgets from thumbnail output limits: accept images
  up to 1 MiB and icons up to 256 KiB, including larger social covers and
  multi-size ICO files.
- Use at most four bounded resize/encode attempts. Output remains a metadata-free
  static PNG limited to 256 KiB for images or 64 KiB for icons.
- Render transparent neutral single-color icons with the theme's foreground
  color in message links and preview headers. Preserve colored, opaque and
  internally shaded artwork, falling back to the original on classification failure.
- Preserve public-address validation, pixel budgets, decoder concurrency limits
  and metadata-only fallback. Session behavior, model calls and protocol are unchanged.

### Upgrade and packages

Follow the [deployment procedure](https://github.com/muggle-stack/cc-remote/blob/v4.0.27/deploy/README.md)
and reload the Web client. No wire-protocol migration is needed from v4.0.26.
Ordinary Wrapper upgrades preserve the independent Claude service.

GitHub Actions builds and attests six Relay/Wrapper bundles, the installer and
checksums. The signed Android APK (unchanged preview.2, versionCode 2) and unsigned
HarmonyOS HAP (unchanged preview.5, versionCode 5) are built locally from this tag.
`MOBILE_BUILD_INFO.json` and `MOBILE_SHA256SUMS` record source and hashes; mobile
assets are not GitHub Actions attested. The HAP requires your own developer/device
signing profile and cannot be installed directly.

Existing Android preview.2 and HarmonyOS preview.5 users need no native reinstall.
No iOS or Desktop installer is included. The Desktop external-browser fix on the
DSH branch is outside this main-branch release. Publishing does not deploy
services or update installed applications.

### Validation

The full local gate passed: 6,224 Python tests with 5 expected skips, Node 24 Web
build/reliability/Lint, Ruff and shell checks. All 26 Chromium/WebKit browser
checks passed, covering previews, themed icons and existing preview interactions.
Android tests, Lint, build, signature and alignment checks passed, as did the
HarmonyOS Release build and package checks.

Browser checks do not replace native WebView device acceptance. Full Android and
HarmonyOS device flows were not rerun for this release; no model prompts were sent.
