# cc-remote v4.0.17

## 中文

v4.0.17 新增网页链接预览，优化本地路径提示和侧聊聚焦。
产品版本 **4.0.17**，通信协议保持 **v74**，Claude Agent SDK 保持 **0.2.157**。

- 正文、侧聊和 Markdown 文件中的网页链接显示网站图标，悬停或点击图标可查看
  标题、摘要和封面。卡片悬浮显示，不挤占正文。
- 网站图标自动按站点发现和共享缓存；元数据加载完毕时，鼠标仍在原位置也能继续
  查看卡片。快速移向相邻链接会立即替换旧提示。
- 本地文件路径提示增加圆角、限制宽度并自动换行，仍能选择和复制完整原始路径。
- 主动打开、展开、停靠或选择 Claude/Codex 侧聊时聚焦其输入框；切换会话后返回、
  刷新恢复侧聊或收到后台输出时不抢焦点。侧聊居中时 `/` 聚焦侧聊，否则聚焦正文。
- 重新打开或刷新正在运行的 Claude 侧聊时，恢复准确的当前轮次和小火花；上一轮遗留的
  后台响应状态不会抢占当前轮次。侧聊在隐藏期间完成时，恢复后显示完成状态。
- Relay 匿名获取公开网页元数据，逐次校验 DNS、重定向和图片地址，限制请求和缓存。
  图标自动获取只发送站点根地址，完整页面预览由用户交互触发。
- 限制图片源像素和边长，仅输出去除元数据的首帧静态缩略图，并限制解码并发。
  超限或无效图片会被省略，链接和页面文字仍可使用；Relay 发布包包含固定版本的 Pillow。

### 升级

安装器管理的部署在独立终端运行：

```bash
cc-remote update --check
cc-remote update --version 4.0.17
```

`cc-remote update` 选择最新稳定版，必要时先更新配对的 Relay + Web，再更新当前设备。
其他设备各自更新，浏览器/PWA 刷新后加载新页面。本版不修改独立 Claude 服务的协议；
普通 Wrapper 更新继续保留该服务及其正在执行的任务。

### 验证与产物

部署快照通过完整本地检查：**5905 项 Python 测试通过、4 项预期跳过**，以及
Node 24 构建、可靠性测试、lint、Ruff 和 Shell 检查。Chromium/WebKit 预览回归
测试通过 16 项，新增侧聊状态回归通过 4 项；真实 Claude 两轮测试验证了 4 次运行中
恢复和 2 次空闲恢复。最终 PR 的 CI 与审查结果以该 PR 为准；发布工作流会在版本
提交上重新执行 CI，再构建和安装验证六个平台／角色包。

产物包含 Linux Relay、Linux/macOS Wrapper 的 x86_64 与 arm64 包，Relay 内含 Web，
并提供安装脚本、SHA-256 校验文件和发布证明。Desktop 与实验 DSH 安装包不在本次 Release 中。

## English

v4.0.17 adds webpage previews and improves local-path tooltips and side-chat focus.
Product version **4.0.17**, wire protocol **v74**, Claude Agent SDK **0.2.157**.

- Show site icons and hover/tap cards with page titles, descriptions and cover images
  in conversations, side chats and Markdown files, without shifting surrounding text.
- Discover and cache icons automatically by origin. Keep cards open as metadata loads
  under a stationary pointer, and replace old popovers immediately between adjacent links.
- Wrap local paths in compact rounded tooltips while preserving the complete copied path.
- Focus explicitly opened, expanded, docked or selected Claude/Codex side chats.
  Returning to a session, restoring its panel or receiving background output does not
  steal focus. `/` targets centered side chat, otherwise the main composer.
- Restore the exact current turn and working indicator when reopening or refreshing
  a running Claude side chat. A stale background response claim cannot take ownership
  from that turn, and work completed while hidden restores as completed.
- Fetch public metadata anonymously through Relay with DNS, redirect and image-address
  validation, request limits and bounded caches. Automatic icon discovery sends only
  the origin; full page previews load on interaction.
- Bound image source pixels and dimensions, normalize only the first frame into a
  metadata-free static thumbnail, and cap decoder concurrency. Invalid or oversized
  images are omitted while links and page text remain usable. Relay bundles include
  the pinned Pillow dependency.

### Upgrade

For managed installations, run `cc-remote update --check`, then
`cc-remote update --version 4.0.17` in an independent terminal. Plain
`cc-remote update` selects the latest stable release and updates the paired
Relay + Web first when needed. Update other devices separately and reload browser/PWA
clients. This release does not change the independent Claude service protocol;
ordinary Wrapper updates preserve that service and its active tasks.

### Validation and assets

The deployed snapshot passed the complete local gate: **5905 Python tests passed,
4 expected skips**, plus Node 24 build/reliability/lint, Ruff and shell checks.
Chromium/WebKit validation passed 16 preview regressions and 4 new side-chat activity
regressions. A real two-turn Claude test verified 4 running restores and 2 idle restores.
Refer to the final PR for its CI and review results. The release workflow reruns CI on
the version commit and builds and validates all six packages.

Assets include Linux Relay and Linux/macOS Wrapper packages for x86_64 and arm64,
with Web bundled in Relay, plus the installer, SHA-256 checksums and attestations.
Desktop and experimental DSH installers are not included.
