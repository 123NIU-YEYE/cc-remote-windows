# cc-remote v4.0.15

## 中文

v4.0.15 修复居中侧聊的 `/` 聚焦快捷键，适用于 Claude 和 Codex。
产品版本 **4.0.15**，通信协议保持 **v74**，Claude Agent SDK 保持 **0.2.157**。

- 使用 `Cmd/Ctrl+Shift+E` 打开居中侧聊后，在非编辑区域按 `/` 聚焦侧聊输入框。
- 侧聊停靠右侧或隐藏时，按 `/` 仍聚焦正文输入框。
- 输入框内的 `/` 正常输入；嵌套弹窗和菜单保持焦点，居中只读侧聊或其他居中面板
  不会把焦点移到背后的正文输入框。

### 升级与验证

安装器管理的部署在独立终端运行：

```bash
cc-remote update --check
cc-remote update --version 4.0.15
```

`cc-remote update` 选择最新稳定版，必要时先更新配对的 Relay + Web，再更新当前设备。
其他设备各自更新，浏览器/PWA 刷新后加载新页面。相对 v4.0.14，本次功能修复仅涉及前端，
无需重启独立 Claude 会话服务。

功能提交通过完整本地检查：**5811 项 Python 测试通过、4 项预期跳过**，以及 Node 24
构建、可靠性测试、lint、Ruff 和 Shell 检查。同一源码快照通过 **36 项 Chromium/WebKit
交互回归**；PR 的 CI、AI 代码和安全审查均已完成，无新增意见。
发布工作流会在版本提交上重新执行 CI，并构建、安装校验六个平台／角色包。

产物包含 Linux Relay、Linux/macOS Wrapper 的 x86_64 与 arm64 包，Relay 内含 Web，
并提供安装脚本、SHA-256 校验文件和发布证明。Desktop 与实验 DSH 安装包不在本次 Release 中。

## English

v4.0.15 fixes the `/` focus shortcut for centered Claude and Codex side chats.
Product version **4.0.15**, wire protocol **v74**, Claude Agent SDK **0.2.157**.

- After opening centered side chat with Cmd/Ctrl+Shift+E, press `/` outside an
  editable field to focus its composer.
- With side chat docked or hidden, `/` continues to focus the main composer.
- Keep normal slash typing in editable fields and preserve focus in nested dialogs
  and menus. Read-only centered chats and other centered panels cannot redirect
  focus to the main composer behind themselves.

### Upgrade and validation

For managed installations, run `cc-remote update --check`, then
`cc-remote update --version 4.0.15` in an independent terminal. Plain
`cc-remote update` selects the latest stable release and updates the paired
Relay + Web first when needed. Update other devices separately and reload browser/PWA
clients. Compared with v4.0.14, this feature fix is limited to the frontend and does
not require restarting the independent Claude session service.

The feature revision passed the full local gate: **5811 Python tests passed,
4 expected skips**, plus Node 24 build/reliability/lint, Ruff and shell checks.
The same source snapshot passed **36 Chromium/WebKit interaction regressions**.
PR CI and AI code/security reviews completed with no new findings. The release
workflow reruns CI on the version commit and builds and validates all six packages.

Assets include Linux Relay and Linux/macOS Wrapper packages for x86_64 and arm64,
with Web bundled in Relay, plus the installer, SHA-256 checksums and attestations.
Desktop and experimental DSH installers are not included.
