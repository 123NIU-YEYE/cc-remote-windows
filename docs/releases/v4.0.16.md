# cc-remote v4.0.16

## 中文

v4.0.16 修复 Claude 后台回复已结束、会话却仍拒绝新消息的问题，并包含居中侧聊的 `/`
聚焦快捷键修复。产品版本 **4.0.16**，通信协议保持 **v74**，Claude Agent SDK 保持 **0.2.157**。

- Claude 省略内部任务输入、后续通知汇入同一回复时，保留原回复归属，让真实结束事件
  正确收尾；重连后的日志重放也保留这一关系。
- 保留其他续行和排队用户输入的独立状态，不重发已接受的请求。
- 使用 `Cmd/Ctrl+Shift+E` 打开居中侧聊后，在非编辑区域按 `/` 聚焦侧聊输入框；
  侧聊停靠右侧或隐藏时仍聚焦正文。保留正常输入和嵌套弹窗、菜单的焦点行为。

v4.0.15 的发布任务已取消，只有源码标签，没有稳定发布包；其快捷键修复随本版发布。

### 升级

安装器管理的部署在独立终端运行：

```bash
cc-remote update --check
cc-remote update --version 4.0.16
```

`cc-remote update` 选择最新稳定版，必要时先更新配对的 Relay + Web，再更新当前设备。
其他设备各自更新，浏览器/PWA 刷新后加载新页面。

**已启用独立 Claude 会话服务的安装，还需升级该服务的运行版本。** 普通 Wrapper 更新
会保留独立服务及其原运行代码，不会自动启用本次服务内修复。按
[服务升级与排空流程](https://github.com/muggle-stack/cc-remote/blob/v4.0.16/docs/claude-session-service.md#first-migration-and-subsequent-deployments)
等待原生任务、后台工作和待处理回调结束后再迁移；不要为清除状态而强制重启活动服务或重发请求。
已有卡住的会话应先保留日志并核对真实结束事件，再按该文档恢复。

### 验证与产物

Claude 修复的完整本地检查通过：**5822 项 Python 测试通过、4 项预期跳过**，以及
Node 24 构建、可靠性测试、lint、Ruff 和 Shell 检查；受影响事件的离线重放也通过。
对应 PR 的 CI、AI 代码审查和安全审查均完成，无新增意见。发布工作流会在版本提交上
重新执行 CI，并构建、安装校验六个平台／角色包。

产物包含 Linux Relay、Linux/macOS Wrapper 的 x86_64 与 arm64 包，Relay 内含 Web，
并提供安装脚本、SHA-256 校验文件和发布证明。Desktop 与实验 DSH 安装包不在本次 Release 中。

## English

v4.0.16 restores Claude input after completed background responses and fixes `/`
focus in centered side chats. Product version **4.0.16**, wire protocol **v74**,
Claude Agent SDK **0.2.157**.

- Preserve the original response owner when Claude omits an internal input and
  later task notifications join the same response. The real terminal Result can
  settle it, including after journal replay on reconnect.
- Keep unrelated continuations and queued human inputs separate without resending
  accepted requests.
- After opening centered side chat with Cmd/Ctrl+Shift+E, press `/` outside an
  editable field to focus its composer. Docked or hidden side chat keeps the main
  composer as the target. Preserve normal typing and nested dialog/menu focus.

The v4.0.15 release run was cancelled: its source tag exists, but no stable packages
were published. Its shortcut fix is included in this release.

### Upgrade

For managed installations, run `cc-remote update --check`, then
`cc-remote update --version 4.0.16` in an independent terminal. Plain
`cc-remote update` selects the latest stable release and updates the paired
Relay + Web first when needed. Update other devices separately and reload browser/PWA clients.

**Installations using the independent Claude session service must also upgrade
that service's runtime.** Ordinary Wrapper updates preserve its running code and
do not activate this service fix. Follow the
[service drain and upgrade procedure](https://github.com/muggle-stack/cc-remote/blob/v4.0.16/docs/claude-session-service.md#first-migration-and-subsequent-deployments)
after native turns, background work and pending callbacks finish. Do not force a
busy service restart or resubmit an accepted request to clear its status. Preserve
journals and verify the real terminal event before recovering a stranded session.

### Validation and assets

The Claude fix passed the full local gate: **5822 Python tests passed, 4 expected
skips**, plus Node 24 build/reliability/lint, Ruff and shell checks. Offline replay
of the affected events also passed. PR CI and AI code/security reviews completed
with no new findings. The release workflow reruns CI on the version commit and
builds and validates all six packages.

Assets include Linux Relay and Linux/macOS Wrapper packages for x86_64 and arm64,
with Web bundled in Relay, plus the installer, SHA-256 checksums and attestations.
Desktop and experimental DSH installers are not included.
