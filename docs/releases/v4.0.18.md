# cc-remote v4.0.18

## 中文

v4.0.18 优化侧边聊天入口和手机布局，并修复 macOS 共享启动器兼容性。
产品版本 **4.0.18**，通信协议保持 **v74**，Claude Agent SDK 保持 **0.2.157**。

- 会话右上角三点菜单新增「侧边聊天」，手机上无需输入 `/btw` 即可打开；
  复用已有侧聊，并沿用主动打开时聚焦输入框的行为。
- 侧聊左上角使用聊天图标、简短标题和 Codex/Claude 标签，去掉冗长副标题。
- 手机侧聊无论是否有内容都保持正常面板高度，避免空会话缩在屏幕底部；
  保留居中展开以及键盘可视区域适配。
- macOS 共享启动器显式使用 macOS 13.0 编译目标及最低系统版本，避免较新的 Swift
  工具链生成当前系统无法启动的应用；覆盖 arm64 和 x86_64 目标。

### 升级

安装器管理的部署在独立终端运行：

```bash
cc-remote update --check
cc-remote update --version 4.0.18
```

`cc-remote update` 选择最新稳定版，必要时先更新配对的 Relay + Web，再更新当前设备。
其他设备各自更新，浏览器/PWA 刷新后加载新页面。普通 Wrapper 更新继续保留独立
Claude 服务及其正在执行的任务。

已生成的 macOS 共享启动器不会随 Wrapper 更新自动重建。若旧启动器提示系统不兼容，
按[共享启动器指南](https://github.com/muggle-stack/cc-remote/blob/v4.0.18/docs/codex-desktop-launcher.md)
保留旧入口后，用新版工具重新生成。官方 Codex App 仍遵循其自身的系统要求。

### 验证与产物

功能提交通过完整本地检查：**5906 项 Python 测试通过、4 项预期跳过**，以及
Node 24 构建、可靠性测试、lint、Ruff 和 Shell 检查。Chromium/WebKit 验证了
Claude/Codex 的空会话、已有内容、展开状态和模拟键盘可视区域；实际 iOS 键盘
不在自动化覆盖范围内。arm64 启动器已检查最低系统版本和签名，x86_64 目标有单元测试覆盖。
PR #66 的 CI、代码审查和安全审查均通过；发布工作流在版本提交上重新执行 CI，
再构建并安装验证六个平台／角色包。

产物包含 Linux Relay、Linux/macOS Wrapper 的 x86_64 与 arm64 包，Relay 内含 Web，
并提供安装脚本、SHA-256 校验文件和发布证明。Desktop 与实验 DSH 安装包不在本次 Release 中。

## English

v4.0.18 improves side-chat access and mobile layout and fixes macOS shared launcher
compatibility. Product version **4.0.18**, wire protocol **v74**, Claude Agent SDK **0.2.157**.

- Open side chat from the session's three-dot menu without typing `/btw` on mobile.
  Reuse the existing chat and its explicit-open composer focus behavior.
- Replace the verbose header with a chat icon, short title and Codex/Claude badge.
- Keep empty and populated mobile chats at the same sheet height, preserving
  expanded mode and keyboard viewport limits.
- Compile shared launchers with an explicit macOS 13.0 target and matching minimum
  system metadata, preventing newer Swift defaults from exceeding the installed OS.
  Both arm64 and x86_64 targets are covered.

### Upgrade

For managed installations, run `cc-remote update --check`, then
`cc-remote update --version 4.0.18` in an independent terminal. Plain
`cc-remote update` selects the latest stable release and updates the paired
Relay + Web first when needed. Update other devices separately and reload browser/PWA clients.
Ordinary Wrapper updates preserve the independent Claude service and its active tasks.

Existing macOS shared launchers are not rebuilt automatically by a Wrapper update.
If an older entry reports an incompatible system, preserve it and regenerate the
launcher with the updated helper using the
[shared launcher guide](https://github.com/muggle-stack/cc-remote/blob/v4.0.18/docs/codex-desktop-launcher.md).
The official Codex App retains its own OS requirements.

### Validation and assets

Feature commits passed the full local gate: **5906 Python tests passed, 4 expected
skips**, plus Node 24 build/reliability/lint, Ruff and shell checks. Chromium/WebKit
checks covered both engines, empty/populated chats, expanded mode and simulated
keyboard viewport changes; a physical iOS keyboard was not exercised by automation.
The arm64 launcher was checked for minimum OS metadata and signing; x86_64 has unit coverage.
PR #66 CI and code/security reviews passed. The release workflow reruns CI on the
version commit, then builds and installation-tests all six packages.

Assets include Linux Relay and Linux/macOS Wrapper packages for x86_64 and arm64,
with Web bundled in Relay, plus the installer, SHA-256 checksums and attestations.
Desktop and experimental DSH installers are not included.
