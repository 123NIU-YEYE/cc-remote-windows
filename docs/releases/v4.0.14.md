# cc-remote v4.0.14

## 中文

v4.0.14 新增侧栏居中放大，并修复侧聊重新打开时闪空、Claude 压缩上下文后无法正常收尾的问题。
产品版本 **4.0.14**，通信协议保持 **v74**，Claude Agent SDK 保持 **0.2.157**。

### 本次更新

- **居中放大**：侧聊、文件、Diff、会话文件、代理详情和远程预览可展开到页面中央。
  `Cmd/Ctrl+Shift+E` 放大当前面板；没有面板时直接打开居中侧聊。快捷键、Escape 和
  点击外部恢复先前的隐藏或右侧停靠状态，原有侧聊快捷键保持可用。
- **保留内容与输入**：切换布局时保留阅读位置、草稿、附件、未保存编辑和预览状态。
  重新打开已有侧聊时，保留完整内容直到历史同步完成，避免先显示、再闪空。
  附件入口改为回形针，附件卡片仍放在输入框上方。
- **键盘和 HTML 预览**：完善菜单、嵌套弹窗和 iframe 的焦点与 Escape 行为；菜单
  打开时不响应面板布局快捷键。保留文档模式和页面 CSP，UTF-16 页面原样传输，
  不注入可选键盘脚本；导航响应不再预估转换后的长度，原始资源的 Range/缓存不变。
- **Claude 正常收尾**：自动压缩产生的摘要不再覆盖真实用户消息身份，避免原生任务
  已完成却仍显示“回答中”。保持引导消息、独立会话服务及断线重放的准确轮次归属。
- **多账号说明**：补全双语 README，说明 Claude/Codex 可以统一使用多个原生 OAuth
  账号和兼容中转 API 账号。

### 升级与验证

安装器管理的部署在独立终端运行：

```bash
cc-remote update --check
cc-remote update --version 4.0.14
```

`cc-remote update` 选择最新稳定版。设备会核对配对的 Relay，必要时先更新 Relay + Web；
其他设备各自更新，随后刷新浏览器/PWA。用户安装预构建产物，无需本地测试或前端构建。

**启用独立 Claude 会话服务的部署**：压缩摘要修复还需要服务进程加载新版代码，仅更新
Wrapper 不会改变旧服务的行为。按[服务排空升级流程](https://github.com/muggle-stack/cc-remote/blob/v4.0.14/docs/claude-session-service.md)更新，
保留正在运行的任务。旧服务已经记录错误收尾的会话不会自动纠正，应先保留证据并核对
准确的原生完成结果，不能通过重发任务或重启活跃进程来清除运行标记。

最终功能提交通过完整本地检查：**5811 项测试通过、4 项预期跳过**，以及 Node 24
构建、可靠性测试、lint、Ruff 和 Shell 检查。另有 **18 项 Chromium/WebKit 回归**通过；
真实 HTTP 用例覆盖 UTF-16 GET/HEAD 响应完整性。最终 AI 代码与安全审查无新增意见。
发布工作流会在版本提交上再次执行 CI，并构建和校验六个平台／角色安装包。

**已知问题**：已观察到 Claude 新建会话在设置完整模型 ID 时偶发失败，根因仍在排查；
本版不包含此项修复。

产物包含 Linux Relay、Linux/macOS Wrapper 的 x86_64 与 arm64 包，Relay 内含 Web，
并提供安装脚本、SHA-256 校验文件和发布证明。Desktop 与实验 DSH 安装包不在本次 Release 中。

## English

v4.0.14 adds centered side panels and fixes blank flashes when reopening side chats
and Claude turns remaining active after context compaction. Product version
**4.0.14**, wire protocol **v74**, Claude Agent SDK **0.2.157**.

- Expand side chats, files, diffs, session files, agent details and remote previews.
  Cmd/Ctrl+Shift+E expands the visible panel or opens centered side chat. The shortcut,
  Escape and outside click restore its previous hidden or docked state.
- Retain reading position, drafts, attachments, unsaved edits and preview state.
  Warm side-chat history stays visible until synchronization completes. Paperclip
  attachment controls retain pending cards above the input.
- Keep focus within menus, nested dialogs and preview frames, and defer layout
  shortcuts while menus are open. Preserve document mode and page CSP. UTF-16 HTML
  passes through without the optional keyboard helper; navigated responses omit
  unknown transformed lengths while raw resource ranges and cache behavior remain intact.
- Do not let Claude compaction summaries replace consumed human message identities.
  Preserve exact completion ownership through steering, service detach and replay.
- Document native multi-account support for Claude/Codex OAuth and compatible API profiles.

### Upgrade and validation

For managed installations, run `cc-remote update --check` followed by
`cc-remote update --version 4.0.14` in an independent terminal. Plain
`cc-remote update` selects the latest stable release. Each device checks and, if
needed, updates its paired Relay + Web before updating itself; update other devices
separately and reload browser/PWA clients. Installation uses prebuilt assets.

**Independent Claude service installations** must also load the new service code
using the [drain procedure](https://github.com/muggle-stack/cc-remote/blob/v4.0.14/docs/claude-session-service.md). A Wrapper-only update
does not change an existing owner's implementation. Preserve active work. Previously
misclassified terminal records need evidence-based recovery against the exact native
completion; do not resend accepted work or restart active processes to clear a badge.

The final feature revision passed the full local gate: **5811 tests passed,
4 expected skips**, plus Node 24 build/reliability/lint, Ruff and shell checks.
**18 Chromium/WebKit regressions** passed, and real HTTP tests cover complete
UTF-16 GET/HEAD responses. Final AI code and security reviews reported no new
findings. The release workflow reruns CI and builds and validates all six packages.

**Known issue:** intermittent Claude session creation failures while selecting a
full model ID remain under investigation and are not fixed in this release.

Assets include Linux Relay and Linux/macOS Wrapper packages for x86_64 and arm64,
with Web bundled in Relay, plus the installer, SHA-256 checksums and attestations.
Desktop and experimental DSH installers are not included.
